# Security Policy

## Supported Versions

Security fixes are released for the latest version of {{name}}, which is the version available on [WordPress.org](https://wordpress.org/plugins/{{slug}}/). Please make sure a vulnerability still applies to it before reporting.

## Reporting a Vulnerability

Please **don't** report security vulnerabilities in public issues, pull requests, or the support forum.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/{{repo}}/security/advisories/new), including:

* The affected version.
* What an attacker can do, and what access they need (e.g. unauthenticated, subscriber, editor).
* Steps or a proof of concept to reproduce it.

You'll get a reply in the advisory. Once a fix is released, the advisory is published with credit to you, unless you'd rather stay anonymous.
